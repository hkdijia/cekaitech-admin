# 变更日志

本文档记录 `cekaitech-admin` 项目内已经落地的功能、配置、脚本和文档变更。

## 2026-05-23

- 新增法律表单事件后台页面 `/legal-form-events`，通过 `miniapp-backend` 的 `POST /api/admin/legal/form-events/page` 查询表单事件，不直连数据库。
- 新增 `src/api/legalFormEvents.ts`，封装法律表单事件分页接口；请求字段使用 `pageNo`、`pageSize`、`orderBy`、`order`、`appCode`、`formType`、`qualityStatus`、`keywords`，返回沿用 `dataList`、`totalCount`。
- 新增 `src/api/legalFormEvents.test.ts`，按 TDD 覆盖法律表单事件分页接口请求路径、请求体和响应解析。
- 主菜单和路由新增“法律表单事件”，路径 `/legal-form-events`，权限码 `admin:legal-form-event:view`；扩展路由测试覆盖入口权限声明。
- 法律表单事件页支持关键词、表单类型、质量状态和小程序筛选，展示分页表格、事件基础字段和 `payloadPreview` 预览列。
- 表单类型和质量状态筛选按当前小程序实际上报值配置，覆盖 `private_lending`、`divorce_agreement`、`generic_template` 和 `valid/low_value`。
- 关键词提示收敛为当前后端实际支持的客户端事件 ID、事件类型和 payload 内容，避免误导为可按用户 ID 搜索。
- 验证通过：`npm.cmd run quality` 通过，10 个测试文件、26 个 Vitest 测试通过，TypeScript 与 Vite 构建通过；构建保留既有 Rollup 注释 warning 和 chunk size warning。
- 同步平台基线 checkpoint：记录当前 HEAD `cf22873`，以及 `npm.cmd run quality` 通过，8 个测试文件、21 个 Vitest 测试通过，TypeScript 与 Vite 构建通过。
- 数据导入页从占位升级为本地预检工作台，支持选择 JSON 文件或粘贴 JSON 文本，在浏览器内解析记录数量、顶层字段完整度和敏感字段提醒。
- 新增 `src/pages/data-import/importPreflight.ts`，封装本地 JSON 预检纯函数；支持常见导出结构 `root[]`、`records[]`、`items[]`、`dataList[]`、`list[]` 和 `data[]`。
- 新增 `src/pages/data-import/importPreflight.test.ts`，覆盖记录数量、字段完整度、敏感字段检测和非法 JSON 状态。
- 数据导入页明确显示“仅本地预检，暂不上传”，当前不新增后端 API、不直连数据库、不控制 crawler。
- 验证通过：`npm.cmd run quality` 通过，9 个测试文件、24 个 Vitest 测试通过，TypeScript 与 Vite 构建通过；构建保留既有 Vite/Rollup warning 和 chunk size warning。
