# 变更日志

本文档记录 `cekaitech-admin` 项目内已经落地的功能、配置、脚本和文档变更。

## 2026-05-21

- 初始化 `cekaitech-admin` 占位仓库。
- 新增项目级 `AGENTS.md`、`README.md`、checkpoint 文档和变更日志。
- 明确管理后台只通过 `miniapp-backend` 受控 API 管理业务数据，不直接写生产数据库，不直接控制本地 `crawler`。

## 2026-05-21

- 确认 `cekaitech-admin` 首版采用后台框架优先策略。
- 确认技术栈为 Vue 3 + Vite + TypeScript + Element Plus。
- 新增 `docs/admin-mvp-design.md`，明确首批页面、目录结构、数据边界、权限阶段和暂不做范围。
- 更新 checkpoint 文档，记录当前处于设计复核阶段。

## 2026-05-21

- 新增 `docs/superpowers/plans/2026-05-21-admin-mvp-shell.md`，作为 `cekaitech-admin` MVP 后台壳的实现计划。

## 2026-05-21

- 初始化 Vue 3 + Vite + TypeScript + Element Plus 后台壳。
- 新增登录占位、后台主布局、左侧菜单、应用/工作区切换和首页工作台。
- 新增用户管理、限制与黑名单、律师认证审核、数据导入、系统设置占位页面。
- 新增路由、mock 登录状态、工作区状态和基础测试。
- 新增本地开发、测试、构建和质量检查命令说明。

## 2026-05-22

- 前端登录从纯 mock store 改为调用 `miniapp-backend` 的后台开发态登录接口。
- 新增 `src/api/http.ts` 和 `src/api/adminAuth.ts`，统一封装后台 API 请求和管理员认证接口。
- 登录成功后保存 `cekaitech-admin-token`，登出时清理本地 token。
- Vite 开发服务新增 `/api -> http://127.0.0.1:8080` 代理，便于本地前后端联调。
- 更新 auth store 测试，覆盖 API 登录成功和登录失败提示。
